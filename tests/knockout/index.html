gclass-anims for Knockout.js v1.0.0-beta.24

Not affiliated with or endorsed by the Knockout team. Official Knockout.js website

MVVM, with motion

Knockout keeps view state in observables and writes it into the DOM with bindings. gclass-anims animates whatever markup is on the page, however it got there. Call initAnimations() once after applyBindings() - and every node a foreach binding adds afterwards is picked up for free.

Get started
Install

GClass ships as the npm package gclass-anims. GSAP is a regular dependency and is installed automatically - nothing is bundled or redistributed. Knockout is a peer of this page, not a dependency of the library.

npm install gclass-anims knockout
Quick start

Import initAnimations once your DOM is ready. From then on, everything is class-driven: add a utility class to an element and it animates - no per-element JS, no config files.

One call, after applyBindings

// main.js
import ko from 'knockout'
import { initAnimations } from 'gclass-anims'

ko.applyBindings(viewModel, document.getElementById('wrapper'))

initAnimations()

Live - a foreach binding over an observableArray

Nothing re-initialises after this point. The button pushes onto the observableArray, the foreach binding inserts real nodes, and each one plays its entrance because the engine is watching the DOM for insertions.

row — inserted by a Knockout foreach binding 
<!-- markup -->
<button data-bind="click: addRow">Add a row</button>
<span data-bind="text: rows().length + ' rows'"></span>

<div data-bind="foreach: rows">
  row <span data-bind="text: id"></span>
</div>

// view model
const viewModel = {
  rows: ko.observableArray([]),
  addRow() { this.rows.push({ id: this.rows().length + 1 }) },
}
Class anatomy

Class anatomy: behaviour (.spawn-up) + trigger (.scroll, .appear) + tunables (.time-1, .ease-back, .priority-2). Combine freely - order in class does not matter.

<!-- behaviour + trigger + tunables -->
<div class="appear scroll spawn-up">…</div>
<div class="appear scroll order ease-expo time-1 priority-2">…</div>
<div class="float">loops forever</div>
<button class="magnet click-expand">magnet + click</button>
PieceClasses
Behaviourspawn-up, float, marquee, magnet
Triggerappear, scroll, preserve
Tunablesorder, ease-expo, time-1, priority-2
Notes
  • No Knockout plugin needed. The engine reads the class attribute and never looks at data-bind. The two are orthogonal - a row can be foreach-bound and .appear-classed at the same time.
  • Bindings that update in place are fine. text and attr rewrite an existing node, which the engine has no interest in. Only foreach, if and template add or remove elements, and those are covered.
  • GSAP stays external. ESM is dist/gclass.esm.js and CJS is dist/gclass.cjs - GSAP is external, not bundled, and the build is tree-shakable with sideEffects: false.
