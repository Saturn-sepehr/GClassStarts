gclass-anims for jQuery

Get started

Running gclass-anims from npm with jQuery .

Install

GClass ships as the npm package gclass-anims. GSAP is a regular dependency and is installed automatically - nothing is bundled or redistributed.

1
npm install gclass-anims

Quick start

Import initAnimations once your DOM is ready. From then on, everything is class-driven: add a utility class to an element and it animates - no per-element JS, no config files.

DOM ready

Call initAnimations() once inside jQuery's ready handler. That is the only hook the page needs.

1
2
3
4
5
6
7
8
// main.js import $ from 'jquery' import { initAnimations } from 'gclass-anims' $(function () { initAnimations() })

Already using the CDN global? $(document).ready(initAnimations) does the same thing.

Class anatomy

Three pieces, in any order: behaviour (.spawn-up), trigger (.scroll, .appear) and tunables (.time-1, .ease-back, .priority-2). Order in class does not matter.

1
2
3
4
5
<!-- behaviour + trigger + tunables --> <div class="appear scroll spawn-up">…</div> <div class="appear scroll order ease-expo time-1 priority-2">…</div> <div class="float">loops forever</div> <button class="magnet click-expand">magnet + click</button>

Notes

  • One ready call. Mark elements you want to keep across navigations with .preserve - all other .appear / .scroll elements replay when they mount.
  • jQuery inserts are covered. A MutationObserver watches the document for insertions, so markup added with .append(), .html() or an Ajax response animates without another initAnimations() call.
  • GSAP stays external. ESM is dist/gclass.esm.js and CJS is dist/gclass.cjs - GSAP is external, not bundled, and the build is tree-shakable with sideEffects: false.
