gclass-anims for Vanilla JavaScript

Framework-agnostic, but this is the zero-framework path. Install the package, import initAnimations once the DOM is ready, then drive everything with class names — no per-element JS or config.

Not affiliated with or endorsed by MDN. Official website

Get started

Install

GClass ships as the npm package gclass-anims. GSAP is a regular dependency and is installed automatically — nothing is bundled or redistributed.

npm install gclass-anims

Quick start

Import initAnimations once your DOM is ready. From then on, everything is class-driven: add a utility class to an element and it animates — no per-element JS, no config files.

Usage

<script type="module">
  import { initAnimations } from 'gclass-anims'

  // the DOM is parsed by the time a module script runs
  initAnimations()
</script>

Dual build: ESM is dist/gclass.esm.js (package.json:10 exports import) and CJS is dist/gclass.cjs (package.json:13 exports require). Both are built by vite.lib.config.js with gsap external and sideEffects: false for tree-shaking.

Class anatomy

Class anatomy: behaviour (.spawn-up) + trigger (.scroll, .appear) + tunables (.time-1, .ease-back, .priority-2). Combine freely — order in class does not matter.

// behaviour + trigger + tunables
<div class="appear scroll spawn-up">…</div>
<div class="appear scroll order ease-expo time-1 priority-2">…</div>
<div class="float">loops forever</div>
<button class="magnet click-expand">magnet + click</button>

Behaviour

spawn-up, float, marquee, magnet

Trigger

appear, scroll, preserve

Tunables

order, ease-expo, time-1, priority-2

Notes

  • What's next. See Installation for requirements and Quick start for the class anatomy (.appear / .scroll + behaviour + tunables). Framework-specific guides — React, Vue, Svelte, Next.js, Vite — are scaffolded alongside this page.
  • Dual ESM + CJS. The package ships dual ESM + CJS and is framework-agnostic. It never touches your build config: every feature is driven by class names you put on markup.
  • GSAP stays external. ESM is dist/gclass.esm.js and CJS is dist/gclass.cjs via vite.lib.config.js — GSAP is external, not bundled. The build is tree-shakable with sideEffects: false and prepublishOnly: build.
