A modest animation library for the HTML you already have.

Sprinkle your HTML with controller, target and action attributes:

<div data-controller="hello">
  <input data-hello-target="name" type="text">

  <button data-action="click->hello#greet">
    Greet
  </button>

  <span data-hello-target="output"></span>
</div>

Write a compatible controller and watch Stimulus bring it to life:

// hello_controller.js
import { Controller } from '@hotwired/stimulus'

export default class extends Controller {
  static targets = ['name', 'output']

  greet() {
    this.outputTarget
      .textContent = `Hello, ${this.nameTarget.value}!`
  }
}

Install

GClass ships as the npm package gclass-anims. GSAP is a regular dependency and is installed automatically - nothing is bundled or redistributed. Stimulus is a peer of this page, not a dependency of the library.

npm install gclass-anims @hotwired/stimulus

Quick start

Import initAnimations once your DOM is ready. From then on, everything is class-driven: add a utility class to an element and it animates - no per-element JS, no config files.

One call, after start()

// main.js
import { Application } from '@hotwired/stimulus'
import { initAnimations } from 'gclass-anims'

const application = Application.start()
application.register('hello', HelloController)

// controllers are already connected by the time start() returns
initAnimations()

Live - nodes appended by a controller

Nothing re-initialises after this point. The controller appends real elements on each click, and each one plays its entrance because the engine watches the DOM for insertions.

0 rows 
<div data-controller="counter">
  <button data-action="click->counter#add">Add a row</button>
  <div data-counter-target="list"></div>
</div>

// counter_controller.js
const row = document.createElement('div')
row.className = 'appear spawn-up time-1'
row.textContent = `row ${n}`
this.listTarget.append(row)

Class anatomy

Three pieces, in any order: behaviour (.spawn-up), trigger (.scroll, .appear) and tunables (.time-1, .ease-back, .priority-2). Order in class does not matter.

<!-- behaviour + trigger + tunables -->
<div class="appear scroll spawn-up">…</div>
<div class="appear scroll order ease-expo time-1 priority-2">…</div>
<div class="float">loops forever</div>
<button class="magnet click-expand">magnet + click</button>

Behaviour

spawn-up, float, marquee, magnet

Trigger

appear, scroll, preserve

Tunables

order, ease-expo, time-1, priority-2

Notes

  • No controller required. A utility class on plain markup animates without a Stimulus controller anywhere near it. gclass-anims never reads data-controller, and Stimulus never reads a utility class.
  • Insertions are covered. A controller that appends, replaces or clones markup gets its .appear / .scroll elements picked up automatically - there is exactly one initAnimations() call on this page.
  • GSAP stays external. ESM is dist/gclass.esm.js and CJS is dist/gclass.cjs - GSAP is external, not bundled, and the build is tree-shakable with sideEffects: false.
