gclass-anims for Enhance

Enhance is HTML-first: pages are documents, and behaviour arrives later as custom elements. gclass-anims animates whatever markup is on the page, which makes the two a natural fit. One initAnimations() call, and the utility classes in the markup below animate with no wiring at all.

This page is deliberately left as plain HTML with no framework at all. The only JavaScript on it is two custom elements and the animation engine.

Get started

Install

GClass ships as the npm package gclass-anims. GSAP is a regular dependency and is installed automatically - nothing is bundled or redistributed. Enhance is a peer of this page, not a dependency of the library. 

npm install gclass-anims

Quick start

Import initAnimations once your DOM is ready. From then on, everything is class-driven: add a utility class to an element and it animates - no per-element JS, no config files.

One call, after the elements are defined

// main.js
import { initAnimations } from 'gclass-anims'

import './elements/row-list.js'
import './elements/row-item.js'

document.addEventListener('DOMContentLoaded', () => {
  initAnimations()
})

Live - an element that appends

The markup below is a plain <ul> with a plain <button>. With JavaScript disabled it still renders and the button does nothing - that is progressive enhancement. The custom element upgrades it, appends real nodes, and each one plays its entrance because the engine watches for insertions.

0 rows

    A second element, reacting to an attribute:

    row-item 
    <!-- the element -->
export class RowList extends HTMLElement {
  get rows() { this._rows ??= []; return this._rows }

  add = () => { this.rows = [...this.rows, this.rows.length + 1] }

  render() {
    this.list.innerHTML = this.rows
      .map((row) => `<li class="appear spawn-up time-1">row ${row}</li>`)
      .join('')
  }
}

customElements.define('row-list', RowList)

    Class anatomy

    Class anatomy: behaviour (.spawn-up) + trigger (.scroll, .appear) + tunables (.time-1, .ease-back, .priority-2). Combine freely - order in class does not matter. 

    <!-- behaviour + trigger + tunables -->
<div class="appear scroll spawn-up">…</div>
<div class="appear scroll order ease-expo time-1 priority-2">…</div>
<div class="float">loops forever</div>
<button class="magnet click-expand">magnet + click</button>

    Behaviour

    spawn-up, float, marquee, magnet

    Trigger

    appear, scroll, preserve

    Tunables

    order, ease-expo, time-1, priority-2

    Notes

    • No framework at all. There is no compiler, no component runtime and no hydration step. The markup above is the page; two custom elements and one animation call are the whole client side.
    • Light DOM is required. gclass-anims queries the document and reads ordinary class attributes. A shadow root would hide both, so these elements stay in the light tree.
    • GSAP stays external. ESM is dist/gclass.esm.js and CJS is dist/gclass.cjs - GSAP is external, not bundled, and the build is tree-shakable with sideEffects: false.
