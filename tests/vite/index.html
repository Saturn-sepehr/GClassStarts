gclass-anims for Vite

Vite is a bundler, not a framework — gclass-anims is framework-agnostic and works with any Vite template. Import and call initAnimations() once from your entry module.

Get started

Install

GClass ships as the npm package gclass-anims. GSAP is a regular dependency and is installed automatically — nothing is bundled or redistributed.

npm install gclass-anims

Quick start

Use the same initAnimations() call as the standalone framework guide, just imported from the Vite entry or the framework root component. For example, Vite + React:

Usage — Vanilla Vite entry

// main.js — the Vite entry
import { initAnimations } from 'gclass-anims'

initAnimations()

// index.html then just uses classes:
// <div class="appear scroll spawn-up">hello vite</div>

Works with any bundler (Vite, Webpack, Turbopack, esbuild). The package ships dual ESM + CJS (package.json:6 main ./dist/gclass.cjs, :7 module ./dist/gclass.esm.js, :10 exports import/require) built by vite.lib.config.js (formats es + cjs, external gsap). It is tree-shakable with sideEffects: false and prepublishOnly: build.

Class anatomy

Class anatomy: behaviour (.spawn-up) + trigger (.scroll, .appear) + tunables (.time-1, .ease-back, .priority-2). Combine freely — order in class does not matter.

// behaviour + trigger + tunables
<div class="appear scroll spawn-up">…</div>
<div class="appear scroll order ease-expo time-1 priority-2">…</div>
<div class="float">loops forever</div>
<button class="magnet click-expand">magnet + click</button>

Behaviour

spawn-up, float, marquee, magnet

Trigger

appear, scroll, preserve

Tunables

order, ease-expo, time-1, priority-2

Notes

  • Any bundler. If you use another bundler, the same import { initAnimations } entry works — for CJS use require('gclass-anims') or require('gclass-anims/dist/gclass.cjs'). Vite-specific guidance here is just for the dev server / HMR setup. Any ES-module or CJS environment should be compatible.
  • GSAP stays external. ESM is dist/gclass.esm.js and CJS is dist/gclass.cjs via vite.lib.config.js — GSAP is external, not bundled. The build is tree-shakable with sideEffects: false and prepublishOnly: build.
  • Requirements. gsap ^3.15 is installed automatically as a dependency (package.json:52 gsap ^3.15.0). Node >=16 is required for build (package.json:56 engines). A modern browser with ES module support is expected — CJS via require() is also available.
